# Journal experiment scripts

This directory publishes the experiment runners, statistical audits, figure
scripts, and tests used in the journal research workspace. Scripts retain their
original computation and defaults. The source publication does not include the
complete research data, trained checkpoints, manuscript, or historical results.

## Setup and standalone checks

Run commands from the repository root in a Python virtual environment. The core
requirements for these checks are in `fusion/requirements.txt`; the OPSD baseline
also uses scikit-learn. These requirements describe supported package ranges,
not the exact versions of every historical training runtime.

```bash
python -m pip install -r fusion/requirements.txt 'scikit-learn>=1.3,<2.0'
python -m pytest -q \
  elsevier_paper/experiments/test_prepare_opsd.py \
  elsevier_paper/experiments/test_opsd_baseline.py \
  elsevier_paper/experiments/test_matched_orchestration.py::test_all_faults_have_matched_outcomes_and_audits \
  elsevier_paper/experiments/test_matched_orchestration.py::test_safe_recovery_does_not_invent_missing_values \
  elsevier_paper/experiments/test_contract_ablation.py::test_numerical_control_matches_existing_fusion
```

These tests construct small inputs locally. They check data validation, causal
features, quantile scoring, equivalent numerical fusion, and matched Python and
LangGraph execution. No API key, measured dataset download, or GPU is needed.

The complete test collection additionally contains integration and archived-result
checks. Running all tests without the inputs below will fail; those failures must
not be described as passing reproduction of the paper.

## Script groups and required inputs

| Scripts | Purpose and prerequisites |
| --- | --- |
| `prepare_opsd*`, `make_opsd_agent_inputs`, `run_opsd_baseline*` | Prepare synchronized measured load/solar observations and run a baseline. Obtain the OPSD source CSV with the columns and date window documented in `prepare_opsd.py`. |
| `run_opsd_native_subset`, `run_measured_agent_graph`, `run_training_autonomy`, `run_full_budget_load` | Model/graph experiments. Require the original `agentic/` and/or `agentic_solar/solar-forecasting-GEFCom2014/` source trees at the repository root, their dependencies, and prepared input files. Those source trees are not supplied by this scripts-only update. |
| `run_contract_ablation` | Uses saved measured graph forecasts in `opsd_measured_full_graph/` and solar calibration data in `opsd_agent_port/`. The numerical-control unit test above is independent of these artifacts. |
| `run_matched_orchestration` | Compares matched post-forecast executors, including failure/recovery cases. Its full benchmark requires saved measured graph forecasts; the two selected tests above construct their own inputs. Requires the fusion package and LangGraph. |
| `run_ablations` | Synthetic fusion ablations; use the synchronized benchmark generator documented in `fusion/README.md`. |
| `calibrate_*`, `compare_*`, `evaluate_*`, `verify_*`, `audit_*` | Analyze experiment-specific observations, forecasts, manifests, and outputs. Inputs are declared in each script; saved-result checks require the original artifacts or rerun equivalents. |
| `replay_solar_checkpoints`, `check_tcn_cpu_numerics`, `summarize_checkpoint_replay` | Require original solar training definitions, splits, scalers, checkpoints, and relevant model libraries. |
| `build_logged_colab_notebooks`, `colab_provenance_runner`, `export_reproducibility` | Record/recover training provenance; require the original source trees and relevant artifacts. These tools cannot recover runtime information that was never recorded. |
| `build_architecture`, `plot_*`, `refresh_paper_figures` | Rebuild figures from source and numerical results. Architecture generation uses `../architecture_viewer.html.in`; data plots require experiment outputs. |
| `test_manuscript_evidence` | Checks local manuscript/evidence consistency; requires manuscript and archived evidence not included in this update. |

OPSD source: https://data.open-power-system-data.org/time_series/2020-10-06/

Use module invocation, for example
`python -m elsevier_paper.experiments.prepare_opsd --help`, so relative imports
resolve correctly. Several audit scripts execute fixed-path workflows instead of
providing a command-line interface; inspect their inputs before executing them.
Paths based on `Path(__file__)` assume the original repository-relative directory
layout. Historical manifests may additionally contain absolute artifact paths.

Generated results, environments, and data/checkpoint directories are excluded from
Git. No historical experiment results are regenerated by publishing these scripts.
